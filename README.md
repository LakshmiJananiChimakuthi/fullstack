# SDP Project - Mental Health & Wellness Platform

A fullstack React application built with Vite, providing mental health and wellness resources.

## Features

- Mindfulness exercises
- Self-assessment tools
- Support groups
- Therapy sessions
- User authentication (Login/Signup)

## Tech Stack

- React 19.2.0
- Vite 7.2.4
- React Router DOM
- ESLint

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

- `/src/pages` - Feature pages (Mindfulness, SelfAssessment, SupportGroups, TherapySessions)
- `/src` - Main components and styling
- `/public` - Static assets
